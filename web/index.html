NETWORKING CORE CONCEPTS

ServerSocket vs Socket: ServerSocket listens on port 5000 via accept(). When a device connects, it returns a Socket dedicated to that client's stream.

Multithreading: Every connection is handled on a dedicated thread (ClientHandler / DeviceSession), preventing blocking socket I/O.

Asynchronous Correlation: Commands carry unique IDs (REQ-101 → RES-101) and are resolved via CompletableFuture, eliminating race conditions across threads.

OBJECT-ORIENTED ARCHITECTURE

Abstraction: Abstract class Device defines template connection methods and lifecycle loops.

Inheritance: Light, Fan, AC, and SmartLock extend Device.

Polymorphism: Overridden processCommand() executes device-specific logic dynamically at runtime.

Encapsulation: Hardware variables (temperature, speed, power) are private and thread-safe.
